# Platform Ops Console

Interactive platform-operations portfolio project demonstrating Kubernetes service health, deployment safety, incident response, and observability workflows.

**Live application:** https://base44-assistant-bee80030.base44.app/

## What it demonstrates
- Multi-region Kubernetes service and cluster health
- CI/CD deployment history, simulated deploys, and rollbacks
- Incident declaration and lifecycle progression
- Prometheus-style golden signals and PromQL examples
- OpenTelemetry distributed traces
- Alertmanager-style rules and simulated silencing
- Kubernetes readiness, HPA, restart, and node-pressure signals

The application uses sample/simulated operational telemetry for demonstration; it is not connected to a production cluster.

## Implementation
This repository is a browser-based implementation of the Platform Ops Console portfolio experience. It uses HTML, CSS, and JavaScript with no local setup required to inspect the source. The live application is published separately through Base44.
